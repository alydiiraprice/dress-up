# Simple Dress-Up Game

## Overview

A very simple 2D pixel-art based game, inspired by old-school dress-up games I used to play on the family computer in the early 2000s. This was a fun weekend project to prevent me from doomscrolling. 


## Features

No AI used to make this.
HTML/CSS frontend. Javascript functions for buttons.


## What I would improve for next time

1. Spend more time planning the UX of the website - additional features, layout, and music
2. Spend more time on the art style and options
3. Add more complex features - save designs to your account, design randomiser, share your design etc.


## How to run

1. Clone repo
2. Run command in the terminal:
`python3 -m http.server`
3. Play game
